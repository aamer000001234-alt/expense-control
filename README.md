# نسخة GitHub Pages — نظام إدارة المصاريف

## النشر

1. أنشئ مستودع GitHub جديدًا للنسخة المنشورة فقط.
2. ارفع `index.html` و`.nojekyll` من هذا المجلد إلى جذر المستودع. لا ترفع ملف سطح المكتب أو النسخ الاحتياطية أو ملفات JSON المالية.
3. من Settings → Pages اختر Deploy from a branch ثم main والمجلد / (root)، واحفظ.
4. استخدم رابط الموقع الذي يعرضه GitHub. لم يُنشأ رابط عام أثناء تجهيز هذه الحزمة.

## الدخول والبيانات

يجب أن تكون البيانات قد رُفعت من النظام الأصلي إلى Firebase. سجّل بحساب مدير Firebase؛ لن تفتح الواجهة قبل استقبال النسخة السحابية. إذا ظهرت نسختان مختلفتان، احفظ المحلية ثم استقبل السحابية. لا توجد كلمة مرور دخول افتراضية في هذه النسخة. إعدادات Firebase العامة وUID المدير ليست مفاتيح إدارية سرية؛ منع الوصول إلى البيانات يعتمد على قواعد Firestore المنشورة.

هذه النسخة لحساب مدير Firebase واحد فقط، وليست نظام صلاحيات سحابية متعدد المستخدمين. لا تمنح القواعد وصولًا عامًا ولا توزع كلمة مرور المدير على مستخدمين آخرين. التخزين المحلي يحتوي البيانات المستلمة على الجهاز؛ استخدم أجهزة موثوقة. عند الخروج تُحجب الواجهة ولكن لا يُمسح التخزين المحلي. المزامنة الحالية تمنع تعارض الإصدارات ولا تدمج العمليات المتعارضة آليًا. حدود Firebase المجانية وحجم النسخة ما زالت تنطبق.

## حدود التحقق

تم حذف كتلة البيانات الأصلية المضمنة وكلمة مرور المدير الافتراضية، وإيقاف الدخول المحلي وتشغيل الواجهة حتى المصادقة واستقبال البيانات، وفحص صياغة JavaScript. يلزم اختبار الدخول واستقبال البيانات بعد النشر واختبار جهازين؛ لم يُنفذ نشر أو اختبار متصفح حي لهذه النسخة بعد. الحسابات الداخلية وصلاحياتها لم تصبح حسابات Firebase مستقلة.
